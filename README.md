<summary><b>ContractGuard — AI Contract Risk Scanner for Creators</b></summary>

<br/>

**ContractGuard** is an AI-powered creator contract defense platform designed to help creators identify risky, unfair, or one-sided clauses before signing brand deals.

<br/>

| Category | Details |
|---|---|
| Problem | Creators often sign brand contracts without legal support, risking unfair payment, usage rights, exclusivity, and termination clauses |
| Solution | AI-powered contract scanning with risk scoring, clause flags, and negotiation-ready counter-language |
| Stack | Next.js, TypeScript, TailwindCSS, API Routes, NVIDIA-hosted Llama 3.1 8B, Rule-Based Fallback Engine |
| AI Layer | Structured JSON analysis through LLM prompting + in-house rule engine with 150+ tested patterns |
| Reliability | Automatic fallback if AI service fails, ensuring every contract still gets analyzed |
| Product Focus | Creator-first risk visibility, negotiation support, and accessible legal-awareness tooling |
| Impact | Helps creators understand contract risks before committing to brand partnerships |
| Repository | [Add Repository Link](https://github.com/HarshitaAsija) |

### What I Built

- Developed an AI-first workflow for uploading and scanning creator contracts  
- Designed a structured risk scoring system for creator-brand agreements  
- Integrated NVIDIA-hosted Llama 3.1 8B for contract interpretation  
- Built a fallback rule-based engine for robust demo reliability  
- Created clause cards, risk categories, and negotiation summaries  
- Designed the experience around non-legal users with clear, actionable outputs  

### Engineering Highlights

- Prompt-engineered the model to return structured risk assessments  
- Added local fallback logic to prevent demo failure during API downtime  
- Built the app using a modern Next.js frontend with TailwindCSS  
- Focused on trustworthy UX, explainability, and creator-oriented product design
